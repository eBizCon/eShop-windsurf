---
name: run-app
description: When the user asks to run the app, this skill will be used to run the app.
---

1. Run `dotnet run --project src/eShop.AppHost/eShop.AppHost.csproj`
2. Wait for the app to start (it will take a few seconds, wait 10 seconds)
3. Login to the dashboard (the login URL will be printed in the console)
